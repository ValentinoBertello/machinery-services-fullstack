# Sistema de Gestión de Servicios de Maquinaria

Aplicación full stack para la gestión interna de clientes y el registro histórico de servicios realizados sobre maquinaria agrícola, especialmente tractores.

## Funcionalidades

- Autenticación de usuarios mediante JWT.
- Alta y consulta de clientes.
- Registro y edición de servicios de mantenimiento.
- Historial de servicios por cliente y rango de fechas.
- Búsqueda, filtros, ordenamiento y paginación.
- Dashboard con estadísticas, gráficos y clientes destacados.
- Documentación de la API mediante Swagger/OpenAPI.

## Tecnologías

**Frontend:** React, TypeScript, Vite, React Bootstrap, React Query y Recharts.

**Backend:** Java 21, Spring Boot, Spring Security, Spring Data JPA y Flyway.

**Base de datos:** PostgreSQL.
